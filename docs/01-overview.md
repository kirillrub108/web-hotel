# 01. Обзор проекта

## Что это

Сайт вымышленной гостиницы «Тихая гавань» — учебный показательный проект. Гость открывает сайт, смотрит номера, фильтрует их по числу мест и цене, открывает карточку и оставляет заявку на бронирование. Администратор гостиницы дальше перезванивает сам.

Продукт намеренно остановлен на заявке. В системе нет оплаты, нет статусов брони, нет личного кабинета и нет проверки занятости дат. Заявка — это строка в таблице `bookings` и ничего больше.

## Какую задачу решает код

| Задача | Где решается |
|---|---|
| Хранить данные гостиницы и номеров | PostgreSQL + [models.py](../backend/app/models.py) |
| Отдавать эти данные машинам | FastAPI, роутеры в [backend/app/routers/](../backend/app/routers/) |
| Показывать их людям | Nuxt SSR, страницы в [frontend/app/pages/](../frontend/app/pages/) |
| Принимать заявку и проверять её | [bookings.py](../backend/app/routers/bookings.py) + [schemas.py](../backend/app/schemas.py) |
| Поднимать всё одной командой | [docker-compose.yml](../docker-compose.yml) |

## Аудитория документации

Разработчик, который видит проект впервые и должен через час уметь добавить поле в модель, эндпоинт в API и блок на страницу.

## Стек и почему именно он

| Технология | Версия | Почему выбрана |
|---|---|---|
| Python | 3.12 | Аннотации типов без обратной совместимости, `str \| None` без импорта |
| FastAPI | 0.115.6 | Валидация тела запроса и OpenAPI получаются из тех же аннотаций, отдельная схема не нужна |
| SQLAlchemy | 2.0, синхронный | Синхронный режим короче в чтении: нет `await` на каждой строке, нет асинхронного пула. Нагрузки, которая оправдала бы асинхронность, у проекта нет |
| Pydantic | v2 | Одни и те же классы описывают ответ API и валидацию заявки |
| PostgreSQL | 16 | Реальная СУБД вместо SQLite: у проекта есть JSON-колонка и внешний ключ |
| Nuxt | 4 | SSR из коробки, файловый роутинг, встроенный прокси в nitro |
| TypeScript | 5.9 | Типы ответов API описаны один раз в [types.ts](../frontend/app/types.ts) |
| Docker Compose | — | Три сервиса, один файл, ноль установок на хосте |

## Осознанно не взято

- **Alembic.** Схема создаётся через `Base.metadata.create_all` в [seed.py](../backend/seed.py). Миграции нужны, когда есть данные, которые нельзя потерять; здесь база пересоздаётся командой.
- **Авторизация.** Все эндпоинты публичные. Читающие ничего не раскрывают, пишущий один и создаёт только заявку.
- **Сервисный слой и репозитории.** Запросы живут прямо в роутерах. Три сущности и пять эндпоинтов не окупают ещё два слоя абстракции.
- **CORS-middleware.** Не нужен: браузер и SSR ходят на тот же origin, см. [02-architecture.md](02-architecture.md).
- **Tailwind и UI-киты.** Один файл [main.css](../frontend/app/assets/css/main.css) с переменными плюс scoped-стили компонентов.
