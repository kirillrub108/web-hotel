# Документация проекта «Тихая гавань»

Инженерная документация сайта гостиницы: FastAPI + Nuxt 4 + PostgreSQL 16 в Docker Compose. Написана по фактическому состоянию кода, каждое нетривиальное утверждение ссылается на файл-первоисточник.

Дата генерации: 10 сентября 2026.

## Документы

| Документ | О чём |
|---|---|
| [01-overview.md](01-overview.md) | Что за продукт, какие задачи решает код, почему выбран такой стек и что осознанно не взято |
| [02-architecture.md](02-architecture.md) | Три контейнера, прокси вместо CORS, границы модулей, порядок запуска |
| [03-runtime-flows.md](03-runtime-flows.md) | Пять сквозных сценариев: каталог, фильтры, заявка, ошибка 404, повторный запуск |
| [04-backend.md](04-backend.md) | Раскладка, подключение к базе, эндпоинты, схемы, зависимости |
| [05-data-model.md](05-data-model.md) | Три таблицы, решения по типам, создание схемы, сид |
| [06-frontend.md](06-frontend.md) | Каталог `app/` в Nuxt 4, роутинг, работа с данными, компоненты, стили |
| [07-infrastructure.md](07-infrastructure.md) | Compose, переменные окружения, образы, команды |
| [08-conventions.md](08-conventions.md) | Правила кода и рецепты: как добавить поле, эндпоинт, страницу, стиль |
| [09-tech-debt.md](09-tech-debt.md) | Слабые места и ограничения, честно и с разделением на долг и осознанный предел |
| [10-onboarding.md](10-onboarding.md) | План изучения на день, топ-7 файлов, вопросы для самопроверки |

## Рекомендованный порядок чтения

Первый день в проекте: 01 → 02 → 03 → дальше по [10-onboarding.md](10-onboarding.md).

Нужно быстро сделать правку: [08-conventions.md](08-conventions.md), там рецепты типовых задач.

Оцениваете, годится ли код для продакшена: [09-tech-debt.md](09-tech-debt.md).

Инструкция по запуску — в [README.md](../README.md) в корне репозитория, здесь она не дублируется.
