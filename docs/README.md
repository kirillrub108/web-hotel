# Документация проекта Kivana

Инженерная документация сайта гостиницы: FastAPI + Nuxt 4 + PostgreSQL 16 в Docker Compose. Написана по фактическому состоянию кода, каждое нетривиальное утверждение ссылается на файл-первоисточник. Источник истины — код; при расхождениях верьте коду (см. [09-tech-debt.md](09-tech-debt.md)).

Последнее обновление: 1 октября 2026. Версия 1.1: аккаунты гостей с подтверждением почты, личный кабинет, бронирование с авто-решениями, CRM и акции, услуги и уборки, письма, админка на ролях (администратор входит как обычный пользователь, `ADMIN_USERNAME` и `SECRET_KEY` больше нет), адаптивная вёрстка для телефона и планшета.

## Рекомендованный порядок чтения

Утверждение проекта: [00-specification.md](00-specification.md). Учтите, что разделы 3–9 и 11 описывают версию 1.0.

Первые три дня в проекте: 01 → 02 → 03, затем по [10-onboarding.md](10-onboarding.md): запуск и демо-аккаунты, backend (04, 05), frontend и вёрстка (06).

Нужно быстро сделать правку: [08-conventions.md](08-conventions.md). Правите стили или таблицы админки — сначала раздел «Адаптивная вёрстка» в [06-frontend.md](06-frontend.md).

Оцениваете готовность к реальным гостям: [09-tech-debt.md](09-tech-debt.md), затем [07-infrastructure.md](07-infrastructure.md).

Инструкция по запуску и таблица переменных — в [README.md](../README.md) в корне репозитория, здесь они не дублируются.
