# Документация проекта Kivana

Инженерная документация сайта гостиницы: FastAPI + Nuxt 4 + PostgreSQL 16 в Docker Compose. Написана по фактическому состоянию кода, каждое нетривиальное утверждение ссылается на файл-первоисточник.

Последнее обновление: 21 сентября 2026. В этой версии появились админка, статусы заявок, защита от двойного бронирования, миграции Alembic и ограничение частоты запросов.

## Рекомендованный порядок чтения

Утверждение проекта: [00-specification.md](00-specification.md), документ самодостаточен.

Первый день в проекте: 01 → 02 → 03 → дальше по [10-onboarding.md](10-onboarding.md).

Нужно быстро сделать правку: [08-conventions.md](08-conventions.md).

Оцениваете готовность к реальным гостям: [09-tech-debt.md](09-tech-debt.md).

Инструкция по запуску — в [README.md](../README.md) в корне репозитория, здесь она не дублируется.
