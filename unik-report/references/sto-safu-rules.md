# Правила СТО САФУ для учебных отчётов

Краткая выжимка из СТО 7.5-04-2017 «Учебные документы. Общие требования к
структуре и оформлению» (Северный (Арктический) федеральный университет).
Используется как «справочник по умолчанию» — если в шаблоне уже есть
соответствующий стиль, всегда брать его.

## Параметры страницы

- Поля: левое 30 мм, правое 20 мм, верхнее 20 мм, нижнее 20 мм.
- Размер бумаги — A4 (210 × 297 мм).
- Ориентация — книжная. Альбомные страницы допустимы только для широких
  таблиц/схем; должны быть отдельной секцией.

## Шрифт и интервалы

- Основной шрифт — Times New Roman, кегль 14.
- Междустрочный интервал — 1.5.
- Абзацный отступ (красная строка) — 1.25 см.
- Выравнивание основного текста — по ширине.
- Перенос слов — автоматический.

## Заголовки

- Заголовки структурных элементов (СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ,
  СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ, ПРИЛОЖЕНИЕ) — прописными буквами,
  без точки в конце, выравнивание по центру, без абзацного отступа.
- Заголовки разделов и подразделов — со строчных букв (первая прописная),
  жирный, выравнивание по левому краю с абзацного отступа. Каждый раздел
  начинается с новой страницы.
- Между заголовком и следующим текстом — один пустой абзац (обеспечивается
  стилем заголовка).
- Точка в конце заголовка не ставится. Если заголовок состоит из двух
  предложений, точка ставится только между ними.

## Нумерация

- Страницы — арабскими цифрами, по центру нижнего колонтитула, начиная с
  4-й страницы (титульный лист, лист задания/замечаний, оглавление —
  не нумеруются, но участвуют в счёте).
- Разделы — арабскими цифрами «1», «2», «3». После номера — пробел.
- Подразделы — двойная нумерация «1.1», «1.2». Подподразделы — тройная.
- В заголовках разделов и подразделов точку после номера НЕ ставить.

## Рисунки

- Рисунок располагается по центру строки, без абзацного отступа.
- Подпись — снизу, по центру, в формате:

  ```
  Рисунок N — Название рисунка
  ```

  Тире — длинное (`—`, U+2014). Точка в конце НЕ ставится. Нумерация —
  сквозная по всему документу или по разделам (в шаблонах САФУ — сквозная).
- На каждый рисунок должна быть ссылка в тексте: «… как показано на
  рисунке 3», «(см. рис. 5)». Без ссылки рисунок включать нельзя.

## Таблицы

- Подпись — СВЕРХУ, выравнивание по левому краю, формат:

  ```
  Таблица N — Название таблицы
  ```

- Шапка таблицы — жирным, выравнивание по центру.
- Содержимое ячеек — обычный текст. Для числовых данных — выравнивание
  по правому краю или по центру.
- Если таблица не помещается на одной странице, на следующих страницах
  пишется «Продолжение таблицы N» (это делает Word при правильной
  настройке свойств строки).
- На каждую таблицу — ссылка в тексте.

## Листинги (программный код)

- Шрифт — моноширинный (Courier New), кегль 11 или 12, междустрочный
  интервал — одинарный.
- Подпись — СВЕРХУ, формат:

  ```
  Листинг N — Название
  ```

- Код приводится без пустых строк-разделителей до и после, отступы —
  пробелами (4 пробела за уровень).
- Длина строки кода — не более ширины полосы текста (примерно 80 символов
  для 11pt). Длинные строки переносить с табуляцией в начале продолжения.

## Формулы

- Формулы располагаются отдельной строкой, по центру.
- Нумерация — справа в круглых скобках, выравнивание правое:

  ```
                    χ² = Σ(mᵢ − m'ᵢ)²/m'ᵢ                       (1)
  ```

- На каждую формулу — ссылка в тексте: «по формуле (1)», «согласно (3.2)».
- После формулы — расшифровка обозначений через «где»:

  ```
  где mᵢ — наблюдаемая частота i-го интервала;
      m'ᵢ — теоретическая частота i-го интервала;
      k — число интервалов.
  ```

- Если в среде нет полноценного редактора формул, использовать линейный
  Unicode-формат: `x̄ = Σxᵢ/n`, `σ² = Σ(xᵢ − x̄)²/n`. Это допустимо для
  учебных отчётов САФУ и хорошо рендерится во всех просмотрщиках.

## Списки

- Маркированный список: маркер — длинное тире `—` (U+2014).
- Нумерованный список: формат «1)», «2)» с круглой скобкой.
- После каждого пункта — точка с запятой, после последнего — точка.
- Перед списком — двоеточие.

## Список использованных источников

- Заголовок «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ» как структурный элемент.
- Источники нумеруются арабскими цифрами с точкой.
- Формат оформления — по ГОСТ Р 7.0.100-2018. Краткий пример:

  ```
  1. Иванов И. И. Название книги : учебник / И. И. Иванов. — Москва :
     Издательство, 2023. — 320 с.
  2. Петров П. П. Название статьи / П. П. Петров // Журнал. — 2024. —
     № 3. — С. 12–20.
  ```

- Все источники должны быть упомянуты в тексте в формате `[N]` или `[N, с. 12]`.

## Сокращения

- «г.» — «год» (при датах). «гг.» — «годы».
- «т. е.» — «то есть» (с пробелом).
- «и т. д.», «и т. п.» — с пробелами и точками.
- «руб.», «коп.», «млн», «млрд» (без точки).
- Заглавные аббревиатуры (СЭД, ИТ, ПК) — без расшифровки на каждой странице,
  но с расшифровкой при первом упоминании: «электронный документооборот (ЭДО)».

## Применение в скилле

В скилле `unik-report` все вышеперечисленные правила выполняются автоматически
за счёт того, что они уже встроены в стили шаблона (Times New Roman 14, поля
30/20/20/20, нумерация рисунков и т.д.). Поэтому скилл просто ссылается на
стили шаблона через смысловые роли (`figure_caption`, `formula`, `heading_1`
и т.д.), а не выставляет форматирование вручную.

Единственное, что нужно делать на стороне скилла:

1. В тексте подписей НЕ писать «Рисунок N —», «Таблица N —» руками. Эти
   префиксы добавит Word из нумерованных стилей.
2. Между знаком тире `—` и текстом — обычный пробел (НЕ неразрывный, не два).
3. В формулах использовать Unicode-символы, а не самодельные комбинации
   букв вроде «mu» или «sigma».
4. В ссылках на структурные элементы — заглавными буквами (ВВЕДЕНИЕ,
   ЗАКЛЮЧЕНИЕ), даже когда они упоминаются в середине предложения.
