# Style discovery — поиск нужных стилей в любом шаблоне САФУ

## Зачем

Шаблоны САФУ для разных дисциплин и от разных кафедр визуально похожи, но
**внутренние идентификаторы стилей различаются**. В одном файле «Подпись к
рисункам» — `styleId="a"`, в другом — `styleId="a4"`. В одном «Листинг» —
`styleId="ac"`, в другом такого стиля нет вовсе. Поэтому скилл не должен
зашивать идентификаторы; он должен искать стили по их человекочитаемому имени
из `<w:name w:val="…"/>`.

## Алгоритм

1. Прочитать `word/styles.xml` из распакованного шаблона.
2. Построить карту `name → styleId`. Имена — те, что лежат внутри `<w:name>`.
3. Применить набор синонимичных шаблонов поиска (см. ниже), от более точных
   к более общим. Первый сматчивший — победитель.
4. Результат записать в `style_map.json`.

## Таблица сопоставления

Каждая смысловая роль ищется по списку имён в указанном порядке. Сравнение —
без учёта регистра, по подстроке.

| Смысловая роль  | Кандидаты имени стиля (в порядке поиска)                  |
|-----------------|-----------------------------------------------------------|
| `heading_1`     | `heading 1`, `Заголовок 1`                                |
| `heading_2`     | `heading 2`, `Заголовок 2`                                |
| `heading_3`     | `heading 3`, `Заголовок 3`                                |
| `heading_4`     | `heading 4`, `Заголовок 4`                                |
| `structural`    | `Структурный элемент`                                      |
| `figure_body`   | `Иллюстрация`                                              |
| `figure_caption`| `Подпись к иллюстрации`, `Подпись к рисункам`, `Caption`   |
| `listing_body`  | `Листинг`                                                  |
| `listing_caption`| `Подпись к листингу`                                      |
| `table_caption` | `Подпись к таблице`                                        |
| `table_header`  | `Заголовок таблицы`                                        |
| `formula`       | `Формула`, `Equation`                                      |
| `bullet_list`   | `List Bullet`, `Маркированный список`                      |
| `numbered_list` | `Перечисление`, `Нумерованный список`, `List Number`        |

| `toc_1`         | `toc 1`, `Оглавление 1`                                    |

| `toc_3`         | `toc 3`, `Оглавление 3`                                    |

## Что делать, если роль не найдена

Это нормально — не во всех шаблонах есть все стили. Например, в шаблонах ЛП
обычно нет «Листинга» и «Подписи к листингу», потому что лабораторные
практикумы по гуманитарным дисциплинам не содержат кода.

Когда роль не найдена:

- Для `figure_caption`, `listing_caption`, `table_caption` — отказаться
  от автонумерации. Подпись формируется как обычный абзац с курсивом по
  центру; в её тексте уже руками пишем «Рисунок N — …». Нумерацию ведём
  своим счётчиком и держим её сквозной в пределах документа.
- Для `figure_body` — использовать обычный абзац с центрированием
  (`<w:jc w:val="center"/>`) и без отступа (`<w:ind w:firstLine="0"/>`).
- Для `formula` — обычный абзац с центрированием, для самой формулы —
  курсив Times New Roman 14.
- Для `listing_body` — обычный абзац с прямым форматированием run:
  `Courier New 11`, одинарный интервал.

Принцип: лучше прямое форматирование, чем создание новых стилей. Новые
стили могут сломать оглавление и нарушить ожидания преподавателя.

## Нумерация (numId)

Стили подписей (`figure_caption`, `listing_caption`, `table_caption`),
заголовков и списков опираются на `numId` из `word/numbering.xml`. Эти
номера тоже могут отличаться между шаблонами, но это нас не касается —
мы лишь применяем `pStyle`, а сама нумерация подтягивается из стиля.

Единственный случай, когда нужно лезть в `numbering.xml`: пользователь
просит «продолжить нумерацию рисунков с 7», а в шаблоне счётчик стоит
с 1. Тогда в нужном `<w:abstractNum>` поправить `<w:start w:val="N"/>`.

## Спецслучай: дефис vs тире в подписях

Стиль подписи в шаблонах САФУ может содержать в своём шаблоне нумерации
текст «Рисунок %1 —» (длинное тире, U+2014) либо «Рисунок %1 -» (обычный
дефис). Это видно в `<w:lvlText w:val="Рисунок %1 — "/>` внутри
соответствующего `<w:abstractNum>`. Менять это не нужно — какой тире-знак
в шаблоне, такой и в итоге.
