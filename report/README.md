# Отчёт по курсовой работе

`Курсовая_работа.docx` — курсовая работа «Разработка web-приложения гостиницы» по дисциплине
«Разработка web-приложений». Документ собирается скриптами из этой папки поверх
«Шаблона КР» с титулом и листом задания из шаблона курсовой (`docs/templates/`), по алгоритму скилла
`unik-report/`. Код проекта, скилл и шаблоны сборка не меняет.

## Сборка документа

```bash
python report/build_report.py
```

Команда пересобирает документ с нуля: копирует «Шаблон КР», анализирует стили (`analyze_template.py`),
переносит и заполняет титул, перерисовывает диаграммы, генерирует текст, вставляет его
(`insert_into_doc.py`, режим replace), чистит оглавление, упаковывает файл и запускает проверки
(`build/verify.py`). Сайт для этого запускать не нужно: скриншоты уже лежат в `assets/screens/`.

- `--skip-diagrams` — не перерисовывать диаграммы, взять готовые PNG.
- `DOCX_VALIDATOR=<путь к validate.py docx-скилла>` — дополнительно проверить файл по схеме OOXML.

**Оглавление** в файле пустое и помечено к обновлению. При открытии Word предложит обновить поля:
согласитесь. Если вопрос не появился, щёлкните по оглавлению и нажмите F9.

## Скриншоты и демо-данные

Этот шаг отдельный, и для него нужен запущенный сайт.

```bash
python report/build/capture.py --up --site
```

- `--up` — выполнить `docker compose up -d --build` и дождаться готовности сайта.
- `--site` — снять скриншоты своего сайта.
- `--analogs` — снять главные страницы сайтов-аналогов.

Без флагов `--site` и `--analogs` снимается и то и другое.

Демо-данные создаёт сид проекта `backend/seed.py` (переменная `SEED_DEMO=true`, значение по умолчанию):
номера, услуги, демо-клиенты, брони, заказы, уборки и акции. Скрипт `build/seed_demo.py` их только проверяет.
Если не хватает заявки на рассмотрении, он добавит её через API.

Учётные данные администратора и демо-клиентов скрипты берут из `docker-compose.yml` или `.env`.

У каждого прогона с `--site` есть побочные эффекты, это нужно для кадров «после отправки»:
- регистрируется гость elena.smirnova@demo.kivana.ru (только при первом прогоне);
- появляется новая бронь демо-клиентки, которую подтверждает администратор.

Сервер ограничивает вход до 10 попыток за 10 минут, поэтому между прогонами выдерживайте паузу около 5 минут.
Начать с чистой базы можно командой `docker compose down -v`, но она удаляет все данные БД.

## Зависимости, нужные только для отчёта

| Что | Для чего |
|---|---|
| Python 3.12+, `lxml`, `python-docx` | сборка и проверки |
| Java (проверено на 25), `build/tools/plantuml.jar` | UML-диаграммы и IE-модель |
| Graphviz (`build/tools/Graphviz-*/bin/dot.exe` или `dot` в PATH) | оргструктура и схема БД |
| `playwright` (Chromium), `requests` | `capture.py`, `seed_demo.py` |
| Microsoft Word, `pywin32`, `pymupdf` | `build/render_pdf.py`: PDF и PNG страниц для визуальной проверки (необязательно) |

Установка инструментов для диаграмм в `report/build/tools`:

```bash
pip install lxml python-docx playwright requests pymupdf pywin32
curl -L -o report/build/tools/plantuml.jar https://github.com/plantuml/plantuml/releases/latest/download/plantuml.jar
curl -L -o gv.zip https://gitlab.com/api/v4/projects/4207231/packages/generic/graphviz-releases/12.2.1/windows_10_cmake_Release_Graphviz-12.2.1-win64.zip
unzip gv.zip -d report/build/tools
```

## Где что лежит

| Путь | Содержимое |
|---|---|
| `build_report.py` | сборка, нумерация рисунков, таблиц и источников, маскирование секретов в приложениях |
| `content/*.py` | тексты разделов, список источников, описания сущностей |
| `build/blocks_ext.py` | расширение `BlockFactory`: рисунки, листинги, таблицы, списки, подписи приложений |
| `build/title.py` | перенос титула и листа задания, сопоставление стилей по имени |
| `build/schema.py` | схема БД из `backend/app/models.py` (через ast) |
| `build/diagrams.py` | генерация IE-модели и схемы БД, рендер всех диаграмм |
| `build/docx_post.py` | поле оглавления и `updateFields` |
| `build/verify.py` | проверки |
| `build/capture.py`, `build/seed_demo.py` | скриншоты и демо-данные |
| `assets/screens/` | скриншоты сайта и аналогов |
| `assets/diagrams/` | исходники `.puml`/`.dot` и PNG диаграмм |
