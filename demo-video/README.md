# Демо-видео Kivana

Автоматическая запись демонстрационного ролика для защиты курсовой: Playwright (Chromium) записывает каждую сцену
отдельным файлом, ffmpeg монтирует ролик с титульными карточками и вшитыми субтитрами.

```bash
./demo-video/run.sh
```

Одна команда: поднимает приложение → сбрасывает БД сидом → записывает 16 сцен → монтирует
`out/client.mp4`, `out/admin.mp4`, `out/full.mp4` и вписывает таймкоды в [SCENARIO.md](SCENARIO.md).

Нужны: Node 18+, ffmpeg/ffprobe, curl; для приложения — Docker (`STACK_MODE=docker`) или локальные
PostgreSQL 16, Python 3.11 и Node (`STACK_MODE=native`, как в `docs/10-onboarding.md`). По умолчанию режим выбирается сам.

## Состав

| Путь | Что это |
|---|---|
| `SCENARIO.md` | Чек-лист функций: роль, функция, шаги, субтитр, таймкод в full.mp4 |
| `run.sh` | Оркестратор всей цепочки |
| `scripts/stack.sh` | Запуск приложения, сброс БД, снимки БД для перезаписи сцен, лог писем |
| `scripts/record.mjs` | Запись сцен; упавшая сцена откатывает БД к снимку и перезаписывается (до 3 попыток) |
| `scripts/scenes/client.mjs`, `admin.mjs` | Сценарии сцен K1–K8 и A1–A8 |
| `scripts/lib.mjs` | Видимый курсор и кольцо клика, плавные движения мыши, посимвольный ввод, метки шагов |
| `scripts/build.mjs`, `video.mjs`, `scenario.mjs` | Монтаж: карточки (lavfi + drawtext), ASS-субтитры, склейка, таймкоды |
| `seed/seed_extra.py` | Доп. сид: 24 прошлых гостя — для пагинации клиентов и заявок |
| `raw/`, `work/` | Сырые записи и промежуточные файлы (в git не попадают) |

Отдельные шаги: `node scripts/record.mjs K4 K5` (только указанные сцены, нужна БД в состоянии перед ними),
`node scripts/build.mjs` (монтаж из уже записанных сцен), `node scripts/build.mjs --pilot K1 A1` (короткий тестовый ролик).

## Как это устроено

- **Курсор и клики.** Init-скрипт рисует курсор и пульсирующее кольцо в слое `popover` (top layer) — они видны и поверх модальных `<dialog>`.
- **Синхронизация субтитров.** На каждом шаге квадрат 12×12 в углу кадра меняет цвет; `build.mjs` находит смены цвета
  покадрово и берёт время субтитров из самого видео (часы записи Playwright «плывут» относительно реального времени).
  В итоговом ролике квадрат закрыт фильтром `delogo`.
- **Письма.** Почта в штатном режиме `console`: ссылки подтверждения и сброса пароля берутся из лога backend.
- **confirm().** Нативный диалог в записи не виден и останавливает кадры, поэтому в браузере записи `window.confirm`
  подменяется (вопрос показывается плашкой, ответ — «OK»). Код приложения не меняется.
